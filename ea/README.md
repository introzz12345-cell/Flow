# FlowPullbackEA – EA เทรดตามเทรนด์สำหรับ MT5

EA ตัวนี้เน้น **เก็บกำไรเล็ก ๆ บ่อย ๆ** และเมื่อเทรนด์แรงจะ **ปล่อยกำไรวิ่งต่อ**
ออกแบบมาสำหรับทุนเล็ก (ประมาณ 1,000 บาท) บน **บัญชี Cent** ใน MetaTrader 5

- ไฟล์ EA: [`FlowPullbackEA.mq5`](FlowPullbackEA.mq5)
- คู่ที่แนะนำ: **XAUUSD** (ใช้กับ EURUSD ได้ ดูหัวข้อ "ใช้กับ EURUSD")
- บัญชี: MT5 บัญชี Cent แบบ **Hedging**
- **ไม่มี** Martingale, Grid หรือการถัวขาดทุน

> ⚠️ **อ่านก่อนใช้:** กลยุทธ์นี้ยังไม่ผ่านการ backtest ต้องทดสอบตามขั้นตอนด้านล่างก่อนใช้เงินจริง
> ผลในอดีตไม่รับประกันผลในอนาคต และไม่ใช่คำแนะนำการลงทุน การเทรดมีความเสี่ยงที่จะเสียเงินต้น

## กฎการเทรด (สิ่งที่ EA ทำ)

### 1. ดูเทรนด์ (กราฟ H1)
| เงื่อนไข | EA จะ |
|---|---|
| EMA50 อยู่เหนือ EMA200 | เปิด **Buy อย่างเดียว** |
| EMA50 อยู่ใต้ EMA200 | เปิด **Sell อย่างเดียว** |

### 2. จุดเข้า (กราฟ M15) ซื้อตอนราคาย่อ
**Buy** ต้องครบทุกข้อ:
1. ใน 3 แท่งล่าสุด ราคาย่อลงมาแตะ EMA20
2. แท่งล่าสุดที่ปิดแล้วปิด **เหนือ** EMA20 และเป็นแท่งเขียว
3. RSI(14) มากกว่า 50

**Sell** ใช้กฎตรงข้ามกัน: แตะ EMA20 จากด้านล่าง ปิดใต้ EMA20 เป็นแท่งแดง และ RSI ต่ำกว่า 50

EA เช็กสัญญาณตอนแท่ง M15 ปิด และเข้าไม้ภายใน 5 นาทีแรกของแท่งใหม่
ถ้าช่วงนั้น spread กว้างเกินไป หรือราคาวิ่งไปไกลแล้ว EA จะไม่ไล่ราคาตาม

### 3. Stop Loss และขนาด lot
- **SL = 1.5 × ATR(14)** ของ M15 ทุกไม้มี SL ตั้งไว้ที่โบรกเสมอ
- EA คำนวณ lot ให้ **ขาดทุนไม่เกิน 1.5% ของพอร์ต** ต่อไม้ โดยใช้สเปกจริงของโบรก ซึ่งรองรับบัญชี Cent
- ถ้า lot เล็กสุดยังเสี่ยงเกินที่ตั้งไว้ **EA จะข้ามไม้นั้น** ไม่ฝืนเทรด

### 4. ทำกำไร 2 ขั้น (เก็บเล็ก แต่ลุยเมื่อมีโอกาส)
| ขั้น | เมื่อไหร่ | EA ทำอะไร |
|---|---|---|
| **TP1** | ราคาวิ่งไป 1 × ATR | ปิด **50%** ของไม้ แล้วเลื่อน SL ไปที่ทุน (+0.1 × ATR) ไม้ที่เหลือจึงไม่มีทางขาดทุน |
| **ครึ่งที่เหลือ (เทรนด์แรง)** | ADX บน H1 มากกว่า 25 | **ไม่ตั้ง TP** ปล่อยวิ่ง ใช้ trailing stop ห่างจากราคา 1.5 × ATR |
| **ครึ่งที่เหลือ (เทรนด์ไม่แรง)** | ADX ไม่เกิน 25 | ปิดที่ **TP2 = 2.5 × ATR** หรือโดน trailing stop ก่อน |

ถ้าไม้นั้นเปิดได้แค่ lot เล็กสุด (แบ่งครึ่งไม่ได้) EA จะปิดทั้งไม้ที่ TP1

**ตัวอย่าง:** XAUUSD ที่ ATR = 4$ ทุน 3,000 USC เสี่ยงไม้ละ 1.5% = 45 USC
- Buy ที่ 4,000.00 → SL 3,994.00 (ห่าง 6$) EA เลือก lot ให้ขาดทุนประมาณ 45 USC ถ้าโดน SL
- ราคาถึง 4,004.00 (TP1) → ปิดครึ่งไม้ แล้วเลื่อน SL ไป 4,000.40
- ถ้าเทรนด์แรง ไม่มี TP ให้ SL วิ่งตามหลังราคา 6$
- ถ้าเทรนด์ไม่แรง ปิดที่ 4,010.00 (TP2)
- กรณีแย่สุดหลังผ่าน TP1: ครึ่งที่เหลือโดน SL ที่ 4,000.40 → **ทั้งไม้ยังได้กำไร**

### 5. ตัวกรองและเบรกนิรภัย
| ระบบ | ค่าเริ่มต้น |
|---|---|
| ไม่เข้าไม้ถ้า spread กว้างเกิน | 15% ของ ATR |
| เทรดเฉพาะช่วงเวลา | 14:00–23:00 เวลาไทย |
| เลี่ยงข่าวแรงของ USD (จากปฏิทินเศรษฐกิจใน MT5) | ก่อนข่าว 30 นาที และหลังข่าว 30 นาที |
| ความเสี่ยงที่เปิดอยู่ | ครั้งละ 1 ไม้ (เปิดไม้ใหม่ได้เมื่อไม้เดิมเลื่อน SL ไปที่ทุนแล้ว รวมไม่เกิน 3 ไม้) |
| จำนวนไม้ต่อวัน | ไม่เกิน 8 ไม้ |
| ขาดทุนรายวัน | ถึง 4% หยุดเปิดไม้ใหม่จนจบวัน |
| พอร์ตลดลงจากจุดสูงสุด | ถึง 20% **ปิดทุกไม้และหยุด EA** |
| ก่อนตลาดปิดสุดสัปดาห์ | ปิดทุกไม้ตอนวันเสาร์ 02:00 เวลาไทย |

## ติดตั้ง

> EA **รันบนแอปมือถือไม่ได้** ต้องใช้ MT5 บนคอมพิวเตอร์ Windows หรือ VPS ที่เปิดไว้ตลอด

1. เปิด MT5 → **File → Open Data Folder** → เข้าโฟลเดอร์ `MQL5` → `Experts`
2. คัดลอกไฟล์ `FlowPullbackEA.mq5` ไปวางในโฟลเดอร์นั้น
3. กด **F4** เพื่อเปิด MetaEditor → เปิดไฟล์ → กด **F7** (Compile) ต้องขึ้นว่า `0 errors`
4. กลับมาที่ MT5 → หน้าต่าง Navigator → Expert Advisors → คลิกขวาเลือก **Refresh**
5. ลาก `FlowPullbackEA` ไปวางบนกราฟ **XAUUSD** (กราฟ timeframe ไหนก็ได้ EA ใช้ M15/H1 เอง)
6. แท็บ **Common**: ติ๊ก **Allow Algo Trading**
7. แท็บ **Inputs**: ตั้ง `InpThaiOffsetHours` ให้ถูก (ดูหัวข้อถัดไป) → กด OK
8. กดปุ่ม **Algo Trading** บนแถบเครื่องมือให้เป็นสีเขียว

เมื่อติดตั้งเสร็จ จะมีแผงสถานะขึ้นที่มุมซ้ายบนของกราฟ

ให้เปิดแท็บ **Experts** (อยู่ในหน้าต่าง Toolbox ด้านล่าง) แล้วหาบรรทัด `sizing check` บรรทัดนี้บอกว่าด้วยทุนตอนนี้ EA จะเปิดกี่ lot และเสี่ยงกี่ %
ถ้าเห็นข้อความ `TRADES WILL BE SKIPPED` แปลว่าทุนน้อยเกินไปสำหรับบัญชีนี้ เช่น ใช้บัญชีปกติแทนบัญชี Cent

## ตั้งเวลาไทย (สำคัญ)

เวลาบน MT5 เป็นเวลาของเซิร์ฟเวอร์โบรก ไม่ใช่เวลาไทย จึงต้องบอก EA ว่าห่างกันกี่ชั่วโมง

1. ดูเวลาบนหัวหน้าต่าง **Market Watch** เช่น `09:42`
2. เทียบกับนาฬิกาไทย เช่น `14:42`
3. ผลต่างคือ `InpThaiOffsetHours` ในตัวอย่างนี้ได้ **5**

โบรกส่วนใหญ่ใช้เวลา GMT+2 ในฤดูหนาว และ GMT+3 ในฤดูร้อน ค่าที่ต้องตั้งจึงเป็น:
- **5** ช่วงประมาณต้นพฤศจิกายน ถึงกลางมีนาคม
- **4** ช่วงที่เหลือของปี

ถ้าค่าที่ตั้งไม่ตรงกับนาฬิกาเครื่อง แผงสถานะจะเตือนด้วยข้อความ `check: this PC suggests ...`

> **ห้ามเปลี่ยนค่า `InpSLATR` ระหว่างที่ยังมีไม้เปิดอยู่** เพราะ EA ใช้ระยะ SL เดิมคำนวณจุด TP1

### ใช้กับ EURUSD
- ตั้ง `InpNewsCurrencies` = `USD,EUR`
- EURUSD วิ่งแคบกว่าทอง เมื่อเทียบกับ spread ตัวกรอง spread (15% ของ ATR) จึงอาจทำให้ **เทรดน้อยมาก** ซึ่งเป็นการกันต้นทุน spread ตามที่ออกแบบไว้
- ถ้าจะผ่อนค่านี้ ให้ backtest ใหม่ก่อนทุกครั้ง

## วิธี Backtest (Strategy Tester)

1. กด **Ctrl+R** หรือเมนู View → Strategy Tester
2. ตั้งค่าแท็บ **Settings**:
   - **Expert:** `FlowPullbackEA`
   - **Symbol:** XAUUSD (หรือชื่อแบบ Cent ของโบรก เช่น XAUUSDc)
   - **Timeframe:** M15
   - **Date:** Custom period อย่างน้อย 1–2 ปี
   - **Modelling:** `Every tick based on real ticks` (ใกล้ความจริงที่สุด เพราะใช้ spread จริงในอดีต)
   - **Deposit:** เท่ากับทุนจริง เช่น 3000 สำหรับ Cent
   - **Leverage:** เท่ากับบัญชีจริง
3. แท็บ **Inputs** ใช้ค่าเริ่มต้นก่อน
4. กด **Start** แล้วดูผลในแท็บ **Backtest** และ **Graph**

> ถ้าโบรกไม่มีข้อมูล tick ย้อนหลังของคู่ Cent ให้ทดสอบกับ XAUUSD บัญชีปกติแทน และตั้ง Deposit 1000 USD
> EA คิดความเสี่ยงเป็น % ผลที่เป็น % จึงเทียบกันได้ ถ้าตั้ง Deposit แค่ 30 USD จะไม่มีไม้ไหนถูกเปิดเลย เพราะ lot เล็กสุดเสี่ยงเกินที่กำหนด

### เกณฑ์ดูผล (ขั้นต่ำที่ควรผ่าน)
| ค่าในรายงาน | ควรได้ | หมายเหตุ |
|---|---|---|
| Total Trades | **200 ไม้ขึ้นไป** | ถ้าไม้น้อยกว่านี้ ผลยังเชื่อถือไม่ได้ |
| Profit Factor | **1.2 ขึ้นไป** | ต่ำกว่า 1.1 ถือว่าแทบไม่มีความได้เปรียบ |

ถ้าจะปรับ ให้ปรับไม่เกิน 1–2 ค่า แล้วทดสอบกับช่วงเวลาที่ไม่ได้ใช้ปรับ

## ก่อนใช้เงินจริง

1. **Backtest** ให้ผ่านเกณฑ์ด้านบน
2. **บัญชี Demo อย่างน้อย 1 เดือน** (ควรได้ 30 ไม้ขึ้นไป) แล้วเทียบผลกับ backtest
3. **บัญชี Cent เงินจริง 1,000 บาท** ด้วยค่าเริ่มต้น แล้วเฝ้าดู 2–3 เดือน
4. ค่อยเพิ่มทุนเมื่อผลจริงใกล้เคียงกับที่ทดสอบไว้

**ความคาดหวังที่สมเหตุสมผล:** ถ้าระบบดี กำไรประมาณ 3–10% ต่อเดือน และจะมีบางเดือนที่ขาดทุน
ถ้าผลดีกว่านี้มากผิดปกติ ให้ตรวจก่อนว่าเพราะตลาดช่วงนั้นเป็นใจ หรือระบบดีจริง

## คำถามที่พบบ่อย

**EA ไม่เปิดไม้เลย?**
ดูบรรทัด `Last:` และแท็บ Experts สาเหตุที่พบบ่อย:
- ปุ่ม Algo Trading ปิดอยู่
- อยู่นอกช่วงเวลาเทรด หรือตั้ง `InpThaiOffsetHours` ผิด
- spread กว้างเกินที่ตั้งไว้
- ทุนน้อยเกินไปสำหรับบัญชีปกติ (ต้องใช้บัญชี Cent)
- ยังไม่มีสัญญาณตามกฎ ซึ่งเป็นเรื่องปกติ บางวันอาจไม่มีไม้เลย

**EA หยุดและขึ้นว่า HALTED?**
พอร์ตลดลงถึง 20% จากจุดสูงสุด EA จึงปิดทุกไม้และหยุดตัวเอง สถานะนี้ค้างไว้แม้ปิดเปิด MT5 ใหม่
ให้ทบทวนสาเหตุก่อนเปิดใหม่ ถ้าจะให้ทำงานต่อ ให้ตั้ง `InpResetPeak = true` ครั้งเดียว แล้วเปลี่ยนกลับเป็น `false`

**ถอนเงินออกแล้ว EA หยุด?**
EA มองว่าการถอนเงินคือ drawdown ให้ใช้ `InpResetPeak = true` ครั้งเดียวหลังถอนเงิน

**ใช้หลายกราฟพร้อมกันได้ไหม?**
ได้ แต่ต้องตั้ง `InpMagic` ให้ต่างกันในแต่ละกราฟ และความเสี่ยงรวมจะเพิ่มขึ้น แนะนำให้เริ่มจากกราฟเดียว
